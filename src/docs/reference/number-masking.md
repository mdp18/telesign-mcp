# Number Masking - API reference

Private SMS and voice sessions between two parties who never see each other's real phone number.

_Generated from Telesign's OpenAPI definitions. Tools in this toolset: `numbermasking_create_sms_session`, `numbermasking_create_sms_voice_session`._

## Create masked SMS session

**MCP tool:** `numbermasking_create_sms_session`

```http
POST https://rest-ww.telesign.com/v1/anonymous/session/sms
```

- **Authentication:** Basic (Customer ID + API key)
- **Request body:** `application/json`
- **Telesign reference:** <https://developer.telesign.com/enterprise/reference/createmaskedsmssession> (updated 2026-09-11)

Use this action to create an anonymous session for SMS communication with number masking. You must use SMS capable-only (not voice capable-only or dual-capable) numbers from Telesign as masking IDs when using this action.

> Looking for the high-level guide page related to this action? Go to [Number Masking - Create masked session for SMS](https://developer.telesign.com/enterprise/docs/number-masking-create-masked-session-for-sms).

#### General requirements
* **Authentication:** [Basic](https://developer.telesign.com/enterprise/docs/authentication#basic-authentication) (easiest to implement) or [Digest](https://developer.telesign.com/enterprise/docs/authentication#digest-authentication)
* **Encoding:** Accepts only **UTF-8 unicode** characters as inputs.
* **Accepts:** `application/json`
* **Responds with:** `application/json`
* **Required headers:** `Content-Type - application/json`
* **Rate limit:** [Default rate limits by product](https://support.telesign.com/s/article/do-you-have-any-rate-limits)

### Body parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `phone_number_1` | string |  | The phone number for one of the end users that will engage in the anonymous exchange. Example: `15555551212`. |
| `phone_number_2` | string |  | The phone number for the other end user that will engage in the anonymous exchange. Must be different from `phone_number_1`. Example: `15558675309`. |
| `validity_period` | integer |  | The amount of time you want the two end users to be able to communicate for. The unit this number represents can be seconds, minutes, hours, or days. The unit used is configured by Telesign; ask our Customer Support Team if you need it changed. The maximum value depends on the units configured for your account, but will always be equivalent to 720 hours. Range: 1 to ∞. Example: `500`. |

### Example request

```json
{
  "phone_number_1": "15555551212",
  "phone_number_2": "15558675309",
  "validity_period": 500
}
```

### Responses

**HTTP 200**

**Success.** Your request was fulfilled and resulted in the creation of a new session. Code against the Telesign status or error codes from the `status.code` and `errors.code` properties in the response payload, rather than the HTTP status code of the response.

| Status code | Description |
|--|--|
| 2700 | Session successfully created |
| 2701 | Session successfully created, the country codes of the phone number and assigned masked_id differs |

**HTTP 400**

**Bad request.** The request could not be understood by the server due to malformed syntax. Code against the Telesign status or error codes from the `status.code` and `errors.code` properties in the response payload, rather than the HTTP status code of the response.

| Status code | Description |
|--|--|
| 2702 | Request for creating session failed, there isn't available masked_id |
| 2703 | Request for creating session failed, invalid session type |
| 2705 | Request for creating session failed, validity_period must be integer greater than zero |
| 2706 | Request for creating session failed, phone number {phone_number} blocked by Telesign |
| 2707 | Request for creating session failed, phone number {phone_number} blocked by customer |
| 2708 | Request for creating session failed, phone_number_1 and phone_number_2 parameters cannot be the same value |

**HTTP 429**

Too many requests.

**HTTP 503**

**Service unavailable.** The system is unavailable, try again. Code against the Telesign status or error codes from the `status.code` and `errors.code` properties in the response payload, rather than the HTTP status code of the response.

| Status code | Description |
|--|--|
| 2704 | Request for creating session failed, internal error |

If this value is `sms_voice`, the session can be used for either SMS or voice communication. Allowed: `sms`, `sms_voice`. Example: `sms`. |
| `session_data.message` | string |  | Any additional description of what happened during the creation of the session. For example, this value might give you a notification that the countries for phone number 1 and the assigned masking ID are different. Example: `Failed to obtain mask for 15555551212`. |

| `session_data.phone_number_2.country_iso3` | string |  | The ISO 3166-1 three-letter country code associated with the phone number. Example: `USA`. |
| `session_data.phone_number_2.masked_id` | string |  | Example: `15557740234`. |
| `session_data.phone_number_2.country_iso2` | string |  | The ISO 3166-1 two-letter country code associated with the phone number. Example: `US`. |
| `session_data.phone_number_2.country_code` | string |  | The one, two, or three-digit country dialing code. Example: `1`. |
| `session_data.validity` | string |  | The period of time that the session will be available. Defined in terms of seconds, minutes, hours, or days. The unit used is configured by Telesign and can be changed at your request. Example: `500`. |
| `session_data.phone_number_1` | object |  |  |
| `session_data.phone_number_1.complete_phone_number` | string |  | The base phone number prefixed with the country dialing code. Example: `15555551212`. |
| `session_data.phone_number_1.country_name` | string |  | The country name associated with phone number. Example: `United States`. |
| `session_data.phone_number_1.country_iso3` | string |  | The ISO 3166-1 three-letter country code associated with the phone number. Example: `USA`. |

| `session_data.phone_number_1.country_iso2` | string |  | The ISO 3166-1 two-letter country code associated with the phone number. Example: `US`. |
| `session_data.phone_number_1.country_code` | string |  | The one, two, or three-digit country dialing code. Example: `1`. |
| `error` | string |  | Unused property. You can disregard this. |

## Create masked voice-SMS session

**MCP tool:** `numbermasking_create_sms_voice_session`

```http
POST https://rest-ww.telesign.com/v1/anonymous/session/sms_voice
```

- **Telesign reference:** <https://developer.telesign.com/enterprise/reference/createmaskedvoicesmssession> (updated 2026-09-11)
